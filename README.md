# ¡ATRAPÁ TODO!

Juego arcade infantil donde el jugador controla una canastita y debe atrapar objetos relacionados con bebés, sumando puntos y evitando obstáculos.

## Características

- 🎮 Controles intuitivos: pantalla táctil (celulares) o mouse/flechas (PC)
- ⏱️ Partida de 60 segundos
- 🍼 Atrapar baberos (+10), chupetes (+15) y biberones (+20)
- 💩 Evitar cacas (-15) y cajas (-30)
- 📈 Sistema de niveles progresivos con objetivos crecientes
- 🔊 Efectos de sonido opcionales
- 📱 Diseño responsive para celulares, tablets y PC
- 🎨 Estética pastel infantil con ilustraciones SVG

## Cómo jugar

1. Atrapa los objetos buenos con tu canastita
2. Evita las cacas y las cajas
3. Completa los objetivos para subir de nivel
4. ¡Maximiza tu puntaje en 60 segundos!
